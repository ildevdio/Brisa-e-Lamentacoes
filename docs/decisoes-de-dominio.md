# Inventário de decisões

## Confirmadas

- Atributos oficiais: Força, Agilidade, Precisão, Inteligência, Sabedoria e Presença.
- A criação distribui `+1, +1, 0, 0, 0, -1` livremente entre os seis atributos.
- Referências `Agilidade/Precisão`, `Constituição/Força` e `Instinto/Sabedoria` são escolhas do jogador entre os dois atributos listados.
- Mana/Prana são valores **iniciais**: mágicas 85–115 e físicas 15–35, conforme a tabela inicial de classes.
- Classes mágicas iniciais: Bardo, Druida, Serafim, Feiticeiro e Mago.
- Traumas são cadastrados pelo Mestre com redução/gatilho/efeito, usando as faixas sugeridas.

## Aguardando regra oficial

- Crítico: gatilho e efeito de Mana/Prana e Lucidez.
- Vida inicial/máxima, Stress máximo, Evasão base e oportunidades por nível.
- Comunidades.
- Nós, custos, conexões e efeitos completos das árvores oficiais.
